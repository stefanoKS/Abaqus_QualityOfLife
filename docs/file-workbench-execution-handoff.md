## 4. Make the material library authoritative

Static inspection found 28 records, including **27 material records** and one container record. It is a legacy protocol-0 pickle representation with nested CAE data strings, Japanese text and symbolic constants. The records include 11 hyperfoam cards (four also viscoelastic), nine hyperelastic cards (Marlow, Yeoh, Ogden or polynomial, two also with Mullins effect), six elastic cards (two also plastic) and one thermal-only card. ## 6. Proposed File screen and two portable document formats

Replace the primary Dashboard/Projects workflow with **File**. On launch show **New model**, **Open…** and recent file paths. In an editable model show **Save**, **Save As…**, its filename and save state. Let Explorer handle folders and names. An engineer makes a variant with Save As. Workspace Results shows active work for the open model and its output path. Provide a way to reopen or monitor an in-flight run after restart without recreating project management. Remove user-facing project creation, revision numbers, history selectors and revision breadcrumbs. Keep existing deep links and historical artifacts readable during migration.

| Proposed extension | User operation | Required payload |
|---|---|---|
| `.aqmodel` | New / Open / Save / Save As | Versioned manifest, stable CAD and component IDs, canonical mm geometry and source provenance, partitions/cavities, catalog pins and exact assigned snapshots, mesh settings and compatible mesh plus reviewed node fixture when present, contacts, motion, step plan, represented width, solver and run settings. State precisely which deck can be rebuilt. No dependency on the old absolute path or database. |
| `.aqresult` | Written after successful extraction, opened read-only | Versioned manifest, submitted setup and material mapping, instance-qualified topology, result index, every referenced frame/history artifact, force and field metadata, display metadata or a validated derivation, solver/extraction status and available provenance/digests. Show DEMO and missing measurements correctly. Open independently with the model file, library and solver unavailable. |

Use typed, versioned ZIP containers with a manifest, relative member names, sizes and hashes. Reuse the existing result interchange and stream large entries. Validate content kind and version on Open, required members, bounded expansion and safe paths before extraction. Overwriting a newer file requires an explicit choice. Re-run the 111 mm / 1.25 mm browser reproduction and verify both changes or distinct recoverable copies.
