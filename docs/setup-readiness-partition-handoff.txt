A user must be able to complete the normal workflow without typing XY or snapping to the border.

Projection policy (make it visible in the preview). Use actual camera inverse, CSS coordinates, device pixel ratio and the model XY plane. Two points determine a directed line and the finite reach of the gesture. Intersect the supporting line with the target material. Select material intervals touched over a positive length by the drawn segment; extend each selected interval to its true boundary hits along the line. A short stroke inside one wall selects that wall's interval, a stroke traversing both walls selects both intervals, and an exterior gesture missing the target is a visible no-hit. This choice preserves the operator's ability to cut one wall at a time. Do not extend every stroke to infinity through additional untouched walls. Show which pieces lie inside material with a solid line and void/outside spans as dashed or omitted. Allow multiple pending guides. If implementing stroke chains with interior junctions, keep intended junctions when noding the graph. Use pixel tolerance only for pointer ergonomics; use the existing documented engineering tolerances in mm for intersections, welding and degeneracy. Recompute from guides when the camera changes for display only.

Topology contract. A stroke crossing rubber is a candidate seam. A material region has been created only if the planar subdivision of the original material produces additional nonoverlapping connected faces of positive area. A single radial cut between outer and inner loops opens an annulus but leaves one connected material region. Retain that stroke as a draft and prompt for another cut. Conversely a single through-stroke can cross BOTH walls of a hollow seal and create two regions at once. A chord that misses the void can also split off a cap. Hole count, click count, intersection count and “crosses a hole” are each insufficient as a success test.

Implement authoritative preview/commit in application Python, reusing packages/engineering/partition.py, canonical Edge/Face loops, geometry.py, spline support, mesh identity and the existing endpoints. Suggested algorithm:
  1. For each targeted face assemble its directed outer loop and hole loops. Distinguish an unfilled void from a neighboring filled region. Compute sorted true boundary intersections on contributing lines/arcs/supported splines; coalesce shared-vertex hits, classify tangencies/overlap and choose material intervals by containment, not alternating counts alone.
  2. Accumulate all in-material seam fragments with all existing face boundaries. Split linework at boundary/inter-seam intersections, weld within a documented mm tolerance, and construct the planar arrangement. Polygonize noded linework or use an equivalent planar graph traversal. Classify cells by a guaranteed interior point in the original material. Discard exterior and cavity interiors. This avoids treating a cavity as a new material region. Count child regions relative to EACH original face. polygonize_full on sampled curves is a useful decision oracle.
