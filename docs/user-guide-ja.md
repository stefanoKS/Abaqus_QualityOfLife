# Abaqus QOL ユーザーガイド

対象: ウェザーストリップ断面の解析を担当する設計・解析技術者。

Abaqus QOL はローカル PC 上で動作する単独利用の作業環境です。データはインターネットへ送信されません。
画面は日本語を既定とし、右上の言語選択で English に切り替えられます。選択は保存され、再読み込み後も
維持されます。数値・単位・材料 ID・節点番号・要素番号など工学的な値は言語を切り替えても変化しません。

起動は `start-abaqus-qol.cmd` をダブルクリックします。初回は Python 3.11 以降と Node.js が入っていれ
ば、リポジトリ内の Python 環境とブラウザ用ビルドを自動で準備し、作業環境とワーカーを起動して、準備完了
を確認してから既定のブラウザを開きます。同じバージョンとデータフォルダーで起動中の場合は、その画面を開きます。
起動に失敗すると、キーを押すまでウィンドウに理由が表示されます。別の作業コピーが同じポートを使用している場合は、
そちらで待機中・実行中のジョブがないことを確認し、元の起動ウィンドウで終了してから、使用したい作業コピーで起動し直してください。
ログインは不要です。

## 1. 画面構成

デスクトップでは、左右のペインをスクロールしても描画領域は固定されます。画面の高さが足りない場合は、左ペインを下にスクロールすると、アセンブリツリーの下にある解析アクションを操作できます。

| 領域 | 内容 |
|---|---|
| 上部バー | 製品ロゴと製品名、**ダッシュボード → 作業画面 → 材料ライブラリ** の順の切り替え、実行環境の表示、言語選択 |
| モデルヘッダー | モデル名、リビジョン、次元、単位系、準備状況。自動保存の状態と **設定を複製** |
| 左ワークエリア | 2 列のワークフロー（各工程の設定状況）とアセンブリツリー |
| プロパティ | 選択中の工程または CAD エンティティの編集。単独でスクロール |
| 描画フィールド | 白い形状・メッシュ・結果ビューポート。右側にズーム / フィット |
| 解析アクション | 各設定工程のアセンブリツリーの下に配置。**入力デッキを作成** → **Abaqus解析を実行**、デッキの準備状況、INP の確認・ダウンロード、解析名、CPU 数、ライセンス状態、実行中の解析へのリンク |
| 下部 | 保存状態、検証メッセージ、実行フェーズ |

起動時は **ダッシュボード** が開きます。ここがファイルの入口で、**新規モデル**、**モデルを開く…**、
**結果を開く…**、最近使ったファイル、**モデルを閉じる** があります。作業画面はこのタブが開いている
文書を表示し、材料ライブラリはそこへ戻ってこられる寄り道です。

狭い画面やブラウザの拡大時はペインが縦に並び、**ワークフローとプロパティ** ボタンで折りたためます。描画フィールドと工程の操作は常に到達可能です。空の描画フィールドは白で、読み込みボタンは置きません。ファイル選択と案内は図面読込の工程が担当します。ダッシュボードでは、実行履歴の絞り込みがカード内で折り返され、長い一覧はページと一緒にスクロールします。狭い幅では各実行が 1 行のラベル付き表示（実行、状態、投入日時、経過、操作）になり、横スクロールの表にはなりません。

ワークフローの各工程には設定状況が表示されます。

- **チェック** : 必要な設定が完了しています。
- **丸** : まだ設定されていません。不足している入力はツールチップと「次の操作」バナーに表示されます。
- **鍵** : 読み取り専用の制約だけに使用します（3D 押し出しプレビューなど）。役割・材料・メッシュ・固定節点・接触の不足は修正可能なため、鍵は表示しません。

工程の完了は「その画面を開いたかどうか」では判断されません。自動保存された実際の設定から判定されます。

## 2. 基本的な流れ

2D の流れは **図面読込 → 構成部品 → 材料設定 → メッシュ → 固定条件 → 接触条件 → 移動条件 → 解析結果** です。メッシュは要素分割だけを担い、**固定条件** が固定節点、**接触条件** が接触則と摩擦を担当します。**入力デッキを作成** と **Abaqus解析を実行** は工程ではなく、**解析結果のプロパティ先頭** に 1 か所だけあります。解析結果はメッシュ・デッキ・実行が無くても開けます。**解析結果** と提出済み設定の参照も引き続き可能です。

1. **ダッシュボード → プロジェクトを作成** でプロジェクト（グループ）と最初のモデルをまとめて作成します。プロジェクトは「5q45」のような入れ物、モデルはその中の解析対象です。**モデル名**を空欄にするとプロジェクト名が使われます。**新しいモデルは空の状態で始まり**、図面未読み込みの Import 画面が開きます。作成画面にサンプルのチェックはありません。以前に作成した公開サンプルのモデルはそのまま参照できます。
2. グループ見出しの **モデルを追加** で同じプロジェクトに 2D / 3D のモデルを追加できます。各モデルは独自のリビジョン履歴と実行履歴を持ち、**リビジョン** で一覧、**モデルを複製** で同じグループ内に独立したモデルを作成できます。
3. **図面読込** で DXF / DWG をそのまま選択します。単位のチェックボックスや確認ダイアログはありません。図面ヘッダーが判定し、その判断をリビジョンに記録します。ミリメートル宣言はそのまま読み込み、その他の認識可能な CAD 長さ単位（インチ、フィート、センチメートル、メートル、米国測量単位など DXF/DWG の列挙）はプロジェクトの mm へ**一度だけ**換算し、元の宣言・換算係数・根拠を併記します。単位なしは mm として解釈し、ヘッダー欠落とは別に記録します。読めないコード、矛盾する $MEASUREMENT、±1e6 mm を超える換算結果は理由付きで拒否し、倍率を推測したり黙ってクランプしたりしません。再読み込み・保存・複製で二重換算は起きません。DWG は **ネイティブ読込** です。CAD コンバータのインストール、ODA の設定、外部サービスへの送信は不要です。対応エンティティは LINE、ARC、CIRCLE、閉じた LWPOLYLINE、SPLINE です。スプラインは制御点・ノット・重みを保った正確な B-スプラインとして、通過点のみのスプラインは AutoCAD 互換の 3 次補間として保持するため、表示もメッシュも弦ではなく作図された曲線に従います。読み込みが終わると新しいリビジョンが作られ、グループ名・モデル名・図面名・リビジョンが表示されます。読み込みに失敗しても直前の図面はそのまま使えます。最初の読み込みに失敗した場合はモデルは空のまま、対処できるエラーが表示されます。**閉じていない図面** も保存・確認可能なモデルとして読み込めます。ビューポートに各スプライン・線分が表示され、離れた 2 本のプロファイルは選択・保存でき、読込サマリーは閉じた材料領域が 0 面であることを示します。CAD で輪郭を閉じるまで、**閉じたシールがありません** という具体的な理由で解析は停止します。1e-6 mm 以内の評価端点は接合し、それより大きい隙間は実測値として報告し、勝手に接続しません。
4. **構成部品** で各構成部品に「ウェザーストリップ（シール部）」「ドアパネル」などの役割を割り当てます。同じ工程で断面領域の一覧と投影分割を扱います。領域を選ぶと強調表示され、構成部品のまま分割対象になります。**この領域に材料を割り当て** が材料設定への明示的なリンクです。
5. **材料設定** で材料を持つすべての領域に材料カードを割り当て、必要に応じて材料特性を編集します。ライブラリは線形弾性、ハイパーフォーム試験データ、**圧縮性 neo-Hookean** ソリッドゴム（C10: MPa、D1: MPa⁻¹）に対応します。
6. **移動条件** のステップ列は割り当てた役割から導出され、読みやすい要約として表示されます。シール 1 つとドアパネル 1 つなら Closing の 1 ステップ、参加するボデーパネルも 1 つならボデー着座→閉じの 2 ステップです。手動のモード選択はありません。**ストローク**（0 以上）と面内の**方向角**（0° = +X、90° = +Y、正は反時計回り）を設定し、ドアとボデーの Δ ベクトルを表示します。**ストローク 0 mm は有効な保持** で、組立位置の役割方向を表示します。新規のドアは 10 mm・−90°（下向き）・1.0 s、保持するボデーは 0 mm が既定です。これは指定移動であり、自動計算した隙間や安全な圧縮量ではありません。初期隙間と変形を確認してください。隙間に達しても適切な接触は保証されません。**ドアパネル移動をプレビュー** と **ボデーパネル移動をプレビュー** は、メッシュ作成前でもプロファイルを指定ベクトルに沿って動かし、正確な組立位置へ戻します。表示だけのプレビューで、ソルバー解析でも保存でもありません。新しい設定は作図位置に配置され、保持された旧オフセットは読み取り専用で表示されます。**接触条件** はハード法線と、ドア↔シール、ボデー↔シール、シール↔シールの 3 つの独立した無次元クーロン係数（0 以上 5 以下、新規は 0.7）を設定します。旧リビジョンは従来の単一係数（0 や明示的な非既定値を含む）を保持します。移動条件を変更しても接触条件は維持されます。有効な変更は自動的に保存されます（**リビジョンを保存** という操作はありません）。同じ移動条件の工程に小さな **解析設定** があり、換算幅 **W**（新規は 100 mm）、全反力/1 mm あたりの力の表示、**ソルバー厚さ t**（新規は 1 mm、読み取り専用）を扱います。W は表示の基準だけで、デッキや断面を変えません。同じ解析設定に **ドアパネル接触圧の出力** があり、新規では既定で有効です。各ステップでドア節点の `CFORCE`（`CNORMF`）と `CPRESS` を既存の出力と一緒に要求し、変形表示用のドア `U` も保持します。**入力デッキを作成** の前に外すと、ドア節点セットと接触要求を省略します。作成済み・投入済みのデッキは変更されず、出力計画を変えた場合は新しい Prepare が必要です（互換メッシュと確認済み固定節点は再利用できます）。
7. **メッシュ → メッシュを生成** で要素分割します。メッシュのサイズ指定・生成・再生成はこの工程だけで行います。
8. **固定条件** で **矩形選択モード** を有効にし、固定したい WS 節点を矩形で囲みます。左ドラッグで選択、**Shift + ドラッグ**でパン、ホイールでズームします。矩形の動作は **置き換え / 追加 / 除外** から選び、**選択をクリア** でやり直せます。選択節点数を確認して **固定節点を保存** を押します。固定されるのは選択した節点だけで、矩形が CAD エッジ全体に広がることはありません。編集可能な旧モデルでは **旧固定エッジ N 本を節点に解決** でハイライトを確認し、その内容を固定節点として保存できます。
9. **解析結果 → 入力デッキを作成** は解析結果プロパティの先頭にあり、確認済みのメッシュ・固定節点・材料・接触・移動から .inp を作成します。メッシュ処理は投入せず、解析も実行しません。現在の設定の工学的入力が揃っているときだけ有効で、デッキの欠落や陳腐化が作成を妨げることはありません。準備できると **入力準備完了** と **入力デッキを確認** / **INP をダウンロード** が表示されます。デッキのカードは実際の状態（未作成、作成中、失敗、キャンセル、より新しいデッキ、メッシュ更新、固定条件の変更）を表示します。作成に失敗した場合はワーカーの診断と失敗した段階を保持し、**診断を開く** と再作成の案内を表示します。**固定節点が変更されています** は記録済みの固定条件ハッシュが実際に異なるときだけ表示します。無効な場合はボタン横の理由が対象工程を示し、分岐・非連結・自己交差・接触側が曖昧な剛体プロファイルはワーカーに投入する前にそこへ表示されます。
10. **Abaqus解析を実行** は、その確認済みデッキと固定条件を実行する別操作です。解析名、CPU 数、**結果フォルダ（任意）** も同じ場所で設定します。結果フォルダを指定すると、抽出成功後にワーカーが `.aqresult` を書き出します（ブラウザを閉じていても実行）。ソルバー成功・抽出成功・ファイル保存は別々の状態として表示されます。ボタンが無効な場合は表示された理由に従い、入力の修正、互換メッシュの生成、固定節点の確認、Abaqus ランチャーの設定、または最新デッキの作成を行ってください。移動量や摩擦だけの変更ではメッシュを再利用できますが、新しいデッキが必要です。
11. **解析結果** は応力があれば **von Mises**・要素プローブで開きます（応力がなければ変位の大きさ・節点プローブ）。**表示量** の切り替え、変位（既定 0–5 mm）と応力（既定 0–0.50 MPa）の独立した範囲（固定の既定、解析全体の自動、最小・最大の編集）、メッシュ辺と節点マーカーの独立トグル、変形倍率、セル・節点プローブを使えます。任意の **材料の輪郭** レイヤーは材料の外周と内部界面を表示し、色見本付きの凡例を添えます。メッシュ辺・節点マーカー・表示量・変形倍率とは独立です。キャンバスは白です。フレーム再生（ループは既定で有効）、ドアパネル応答曲線、編集可能な間隔での荷重 CSV またはドア面圧 CSV の書き出し、生データ CSV のダウンロードも行えます（欠測は 0 ではなく空欄）。

### 自動保存・複製・履歴

作業画面は **1 つの現在モデル** を編集します。有効な設定は自動的に保存されます。数値を入力して Enter か欄外へ移動する、役割や材料カードを選ぶ、オプションを切り替えると、コンパクトな **自動保存済み** 表示で現在のリビジョンが更新されたことが分かります。**リビジョンを保存** ボタンも接触条件専用の保存操作もありません。保存中は **変更を保存しています…** と表示され、入力デッキ作成はその一時的な理由で待機します。保存に失敗した場合は **保存に失敗しました** と原因、**再試行** ボタンが表示され、入力した値は画面に残ります。別タブとの競合は、自分が変えた項目だけを新しい現在リビジョンに載せ替えて解決します。相手が換算幅を、自分がメッシュサイズを変えた場合は再試行で両方が残ります。同じ項目を両方が変えた場合はその項目名を示し、**最新のリビジョンを再読込** を選べます。上書きはしません。

**保存と名前を付けて保存（ポータブルモデル）。** ヘッダーに現在の `.aqmodel` ファイル名、または **ファイル未保存** が表示されます。**保存** は現在のモデルをそのファイルへ書き込みます（Ctrl+S も同じ）。最初の保存または **名前を付けて保存…** ではフォルダとファイル名を指定します。モデルファイルには図面の出所、CAD ID、材料スナップショット、メッシュ設定、互換メッシュと確認済み固定節点、接触・移動・実行設定が含まれます。このセッションの保存後にディスク上のファイルが変わっている場合は上書き前に確認し、名前を付けて保存は元ファイルを変更しません。モデルファイルを開くと、この環境に独立した現在リビジョンが作られ、他の人が開いているファイルを上書きしません。

**結果ファイル。** 解析結果プロパティで **結果フォルダ（任意）** を設定してから実行します。抽出に成功すると、`<モデル>-<解析名>-<日時>-<短いID>.aqresult` がそこへ書き出されます。保存だけが失敗した場合はソルバー・抽出とは別に表示され、解析を再投入せずに再試行できます。ダッシュボード → ファイル → **結果を開く…** で読み取り専用の結果（フレーム・履歴・インデックス・出所）を開けます。

別モデルとして分岐するときは **設定を複製**（ダッシュボードの **モデルを複製**）を明示的に使います。新規プロジェクト / モデルの作成は空のモデルを開始します。実行履歴の **設定** は投入したリビジョンをそのまま読み取り専用で開き、その後の編集でセットアップ・メッシュ・デッキ・結果が書き換わることはありません。

### 操作手順（4 つ）

**空のモデルを作成して図面を読み込む。** ダッシュボード → 新規プロジェクト → プロジェクト名と最初のモデル名を入力 → プロジェクトを作成。モデルは図面未読み込みの状態で開きます。単位確認なしで DXF または DWG を選択します。単位なしの図面は mm として解釈され、その扱いが読込サマリーに表示されます。ビューポートには読み込んだ形状が表示され、そのリビジョンの元図面はダウンロードできます。

**モデル／プロジェクトのアーカイブと削除。** ダッシュボードに **アーカイブを表示** と、各モデル・プロジェクトのアーカイブ／復元があります。アーカイブ済みは既定で非表示になり、読み取り専用で開きます。リビジョン・実行・ダウンロードは引き続き参照できます。完全削除は通常の一覧（アーカイブしていない項目を含む）から直接実行できます。1 つの確認ダイアログが対象、種別、子モデル数、リビジョン数、ジョブ数、削除される成果物、実行中・未確定の処理を示し、名前の完全一致入力で実行します。キャンセルまたは Esc では何も変わりません。確認後に削除範囲が変わった場合は、更新された件数を示して再確認を求めます。実行中・待機中・未確定の処理がある場合は削除できません。共有図面は最後の参照とともにだけ削除され、材料ライブラリ・兄弟モデル・無関係なグループは残ります。

**別のモデルや過去のリビジョンを開き直す。** ダッシュボードでモデルカードを開くか、**リビジョン** から過去のリビジョンを選びます。再読み込み、戻る / 進む、ロゴ、作業画面ボタンは同じ規則で解決します。無効なリンクは、存在しないリビジョン名を示して **プロジェクト一覧へ戻る** を提供し、別のモデルを勝手に開くことはありません。作業画面ボタンは、最後に明示的に開いたモデルを復元します。

**実行中の進捗を確認する。** 診断画面の先頭に、フェーズ、ソルバーと抽出の状態、現在のステップと增量、模擬ステップ時間、最終更新、進捗バーを表示します。進捗はソルバーが報告した模擬時間と設定時間の比率であり、実時間や完了予想時刻ではありません。2 ステップ解析ではステップ名（Body seating / Closing）と役割（ボデーパネル / ドアパネル）が並び、実行中のステップが強調されます。100% はソルバーと結果抽出の両方が成功した場合だけです。抽出中・抽出失敗では 100% 未満のまま理由を表示します。ワーカーのハートビート停止やライセンス待ちも明示します。

**ボデーパネル着座 → ドアパネル閉じの 2 ステップ解析。** 構成部品でシール、ドアパネル、ボデーパネルをそれぞれ 1 つ割り当てると、移動条件のステップ要約が自動的に 2 ステップになります。ボデーパネルのストローク・方向角・着座時間、続いてドアパネルのストローク・方向角・時間を設定します。ステップ 1 でボデーパネルを移動してドアパネルを保持し、ステップ 2 でボデーパネルを着座位置に保持したままドアパネルを閉じます。シール変形と接触状態はステップ間で引き継がれます。メッシュには両方の剛体プロファイルが R2D2 として含まれます。X 方向の戻り、鉛直部分、同じ X の端点を含む曲線プロファイルも扱えます。デッキは CAD の開いたチェーンを位相順にたどり、元の R2D2 要素と節点の同一性を保ち、初期接触部の局所測定から物理的な SPOS 面を選びます。分岐・非連結・自己交差・接触側が曖昧なプロファイルは、デッキ作成前に型付きの理由で拒否されます。結果では表示ステップを切り替え、ボデーパネルとドアパネルの移動量・反力を別々に確認できます。このテンプレートは入力生成と統合テストのみで、**ライセンスを使用した解析では未検証**です。検証が完了するまでは未認定として扱ってください。

**移動量や摩擦を変えて同じ固定条件で再実行する。** モデルを開き、移動条件（または接触条件）で値を変更します。変更は自動保存され、メッシュは互換のまま維持され、固定条件の工程も表示・操作可能なまま確認済みの固定節点を保持します。解析アクションでその固定節点のまま新しい入力デッキを作成し、Abaqus 解析を投入できます。以前のデッキ・固定条件・結果は引き続き参照できます。材料カードの値の変更もメッシュを再利用します。メッシュサイズやメッシュを決める役割を変えた場合は新しいメッシュと固定節点の再確認が必要で、その旨が工程に表示されます。

**意図的にメッシュを再生成し、固定節点を確認し直す。** メッシュ工程で「メッシュを生成」を選びます。確認済みの固定条件がある場合は、影響を受ける固定節点の数が表示され、**再生成する** か **キャンセル** を選ぶ必要があります。キャンセルすれば状態は変わりません。再生成が成功すると固定節点は未選択の状態から始まるため、入力デッキを作成する前に固定条件を確認し直します。節点番号やメッシュのバイト列が同じでも再確認が必要です。

**数値の誤入力は保存前に直す。** 入力した数値が無効でも、その文字列は画面に残ります。必須の数値欄を空にした場合も無効であり、「変更なし」として以前の値を保存することはありません。理由が欄の下に表示され、何も書き込まれず、**メッシュを生成**・**入力デッキを作成**・解析投入は無効になります。無効なまま別の工程へ移動しようとすると同じ説明が表示され、移動しません。値を直すか、**Esc** で保存済みの値に明示的に戻してください。勝手に元の値へ戻して保存が進むことはありません。

**視点操作と構成部品名の変更。** マウス中ボタン（または Shift + 左ボタン）のドラッグで視点を移動できます。移動中にページはスクロールせず、ホイールのズームもそのまま使えます。アセンブリツリーの鉛筆ボタンで構成部品の表示名を変更でき、Enter で保存、Esc でキャンセルします。リビジョンを保存すると名前も保存されます。元の図面名と形状・FE の同一性は変わらないため、名前の変更でメッシュが作り直されることはありません。メッシュ確認の構成部品行には、表示名・役割・解析への含否・要素タイプ・要素数が表示され、意図的に除外したボデーパネルは「要素なし」ではなく「解析から除外」と表示されます。

**実験データを貼り付ける。** ハイパーフォームのカードで **表データを貼り付け** を開くと、貼り付け内容はまず確認用に解析されます。3 列（公称応力、軸公称ひずみ、横公称ひずみ）を想定し、値は丸めず・並べ替えずに元の順序で保持します。空行は無視し、文書化されたヘッダー 1 行だけを受け付けます。それ以外の不正な非空行は行番号付きで表示され、**反映** は押せません。キャンセルや不正な貼り付けで保存済みカードが変わることはありません。受け付けた行は反映前のプレビュー曲線で確認できます。

**画面と API が一致しないとき。** このタブが読み込んだビルドと実行中の API が異なる場合、または API の版が変わった場合、ヘッダー下に 1 つの案内が表示されます。古いタブなら **再読み込み**、API の版違いなら Abaqus QOL を閉じて `start-abaqus-qol.cmd` から起動し直します。一致するまで、プロジェクト作成・読込・デッキ生成・解析投入は無効です。半端に一致した組でプロジェクトを変更したり、解析を投入したりしないための仕様です。

**2 つのタブと固定条件。** 固定節点の保存には、そのタブが読み込んだ固定条件の版が使われます。別のタブが先に新しい選択を保存していた場合、上書きせずに現在の節点数を示して保存を拒否します。固定条件を開き直して現状を確認してください。入力デッキの作成も、確認した固定条件そのものを送るため、他タブの新しい節点を黙って取り込むことはありません。

### メッシュの再利用と無効化

メッシュは形状・構成部品の役割・領域の充填状態・分割条件で識別され、解析条件とは切り離されています。移動量・ステップ時間・摩擦係数・材料値の変更ではメッシュと固定節点は維持され、入力デッキの作り直しだけが必要です。形状、役割、空洞の充填、メッシュサイズや分割条件を変更すると旧メッシュは非互換となり、画面にその旨が表示され、新しいメッシュ上で固定節点の再確認が必要になります。作成済みのデッキも投入できなくなります。再読み込みや再表示で自動的に再メッシュされることはなく、確認済みのメッシュとハイライトが復元されます。

投入済みの設定は、その入力デッキが記録したメッシュと固定節点で再生されます。保存されたメッシュの同一性を確認できない場合は、新しいメッシュにラベルを重ねるのではなく、表示できない理由を画面に示します。
## 3. 材料

上部の **材料ライブラリ** タブで、共有・版管理された材料を管理します。作業画面の **材料設定** は、領域への割当と割当済み版の確認だけを行います。

材料ライブラリでは、検索・新規作成・複製・名前変更・編集・アーカイブ・復元ができます。カードを編集すると版が追加され、以前の版はそのまま参照・読み込み・比較に使えます。**版履歴** には作成日時と、その版を固定している保存済みリビジョンが表示されます。応力－軸ひずみ、横ひずみ－軸ひずみの比較グラフは、選択した版の実測点のみを表示します（フィットや外挿は行いません）。

**モデル内カードの取込** は、モデルのリビジョンから新しいライブラリ項目を作成します。名前での自動統合は行わないため、同名でも別のカードは統合されません。

**CAE 材料ライブラリの取込** は、Abaqus/CAE の `.lib` を実行せずに読み取り、各レコードの材料則、工学
ファミリ、そして **新しい 2D 解析に使用できるか / 密度が必要か / 構造則がないか** を表示します。正しい
形式のレコードはチェックすれば登録されます。登録と実行は別の判断です。**ファミリ** はカードごとに宣言
します（既定はヤング率からの推定で、取込前に変更できます）。混在ライブラリでも金属カードを誤分類しません。
同一内容の再取込は既存項目を再利用し、同名で内容が異なるレコードは両方登録して内容サフィックスで区別
します。**CAE 材料ライブラリの書出** は CAE が生成した元のレコードバイトをフォルダへ書き出し、往復を
検証してから原子的に公開します。元のストリームをそのまま書くため *元ファイル* として明示します。

**登録済み CAE 材料則。** 登録されたカードは、ソースの材料則（ハイパーフォーム、超弾性、粘弾性、塑性、
Mullins、熱）をオプション・列・行までそのまま読み取り専用で表示します。簡易エディタはこの材料則を書き
換えません。ソースに密度がない場合、密度欄は空のままで「密度が必要です」と表示されます。値を入力して
保存すると新しい版が作られ、保存済みリビジョンは以前の版を固定したままなので過去の実行は変わりません。
直接指定の `*Hyperfoam` 行はキーワード順のまま 1 行 8 値以内に分割して出力します。横ひずみフラグが OFF の
試験データは有効 2 列で出力し、ゼロ埋めの保存列を実測値として出しません。

**工学ファミリと要素タイプ。** 各カードはファミリを宣言します。ポリマーの四辺形は低減積分 **CPS4R**、
変形する金属の四辺形は完全積分 **CPS4** です。三角形のシール要素は CPS3、剛体プロファイルは R2D2 の
ままです。INP はタイプごとに要素ブロックを分け、領域ごとの ELSET と断面を出力します。ファミリの変更は
新しいメッシュを要求し、係数だけの変更はメッシュと確認済み固定節点を再利用してデッキだけを陳腐化させます。

**ファイル文書と閉じる。** ファイル操作から作成・読み込んだモデルは、アーカイブも削除もできない内部の
*ファイル文書* に属するため、プロジェクトがアーカイブされていても編集できます。ダッシュボードの
**モデルを閉じる** は、閉じる文書名を示したうえで**このタブの**文書セッションだけを終了します。最近
使ったファイル、保存済みモデル、投入済み解析は影響を受けません。ディスク上のファイルが作業中の
リビジョンより古い場合は、**保存して閉じる / 保存せずに閉じる / キャンセル** を選べます。保存、
`Ctrl+S`、名前を付けて保存、保存して閉じるは同じ経路で、有効な編集を先に確定し、その確定で返った
リビジョンを書き出します。アーカイブされたグループに残ったモデルは **編集可能なコピーとして復元** で
新しい編集可能モデルとして復元でき、元のモデルはアーカイブのまま残ります。

作業画面で領域を選び、モデル内カードを選ぶか **材料ライブラリから割当** を選びます。割当済みのライブラリ版が表示され、新しい版がある場合は **版 N を採用** で値を取り込みます。形状とメッシュは再利用され、新しいリビジョンと入力デッキが必要になります。

**材料設定 → 材料カード一覧** に既存のカードが表示されます。

- **新規作成** : 空の線形弾性カードを作成します。
- **複製** : 選択中のカードを複製します。
- **削除** : いずれかの領域で使用中のカードは削除できません。先に割当を解除してください。
- **材料名 / 表示色** : 自由に変更できます。
- **材料モデル** : 線形弾性 または ハイパーフォーム（試験データ）を選択します。

線形弾性では密度、ヤング率、ポアソン比を入力します。ハイパーフォームでは一軸試験データ（公称応力、
軸公称ひずみ、横公称ひずみ）を表形式で編集できます。表計算ソフトの 3 列を貼り付けることもできます。
貼り付けは元の行番号と拒否理由を確認してからカードを置き換えます。

入力値に問題がある場合は、保存前にエラーが表示され **リビジョンを保存** が押せなくなります。工学的な
助言（例: 軸ひずみが単調増加していない）は警告として表示されますが、保存は妨げません。

カードの値が実際に変わった場合のみ、保存時にカード版数（v）が増えます。過去のリビジョンは当時の材料値
を保持したまま残ります。未割当の材料カードは入力デッキに出力されません。

### 1 つのシール領域を材料分割する

**構成部品** の工程で、材料を持つ 1 つのシール領域を、結合した一致界面を共有する独立選択可能な子領域に分割できます。操作者はビューポートに投影ガイドを描き、ブラウザが三角形や FE ラベルを書き換えることはありません。これは材料の分割であり、物理的な隙間ではありません。

1. 構成部品の領域一覧で領域を選ぶ（または面をクリックする）と、**領域を分割** の横に対象が表示されます。選択は強調表示され、構成部品から離れません。**この領域に材料を割り当て** が材料設定を明示的に開きます。
2. **領域を分割** を押し、対象の壁を横切る任意の 2 点をクリックします。ガイドは境界に触れる必要も、XY を入力する必要もありません。サーバーはガイドの支持線と正規の解析境界を交差させ、描いた線分が実際に触れた材料区間を選び、真の境界交点まで延長します。1 つの壁の内側だけの短い線分はその壁を切断し、中空シールの両方の壁を横切る線分は両方を選んで 1 回の適用で 2 領域を作ります。
3. プレビューは正規の領域数と面積を示します。環状領域を開くだけで 1 つの連結領域が残る場合はドラフトとして保持され、**分割を適用** は無効のままです。2 本目を描いてください。対象材料に当たらないガイドは目に見える「当たりなし」になります。複数ガイドのうち継ぎ目が未完成のものも表示されます。該当ガイドを削除するか反対側の壁を切断してください。各ガイドの削除、**直前のガイドを取り消す**、**分割を取消**、**Esc** が使えます。座標入力は任意の代替で、ガイドを追加するものであり必須ではありません。
4. **分割を適用** は 1 つのリビジョンを原子的に保存します。各子領域は親の材料と安定した CAD ID を継承し、直線・円弧・スプラインの解析エッジを保ちます。内部継ぎ目は外部接触から除外され、両側の 1 要素ずつが共有します。必要なら異なるカードを割り当てて **リビジョンを保存** します。
5. トポロジが変わるとメッシュダイジェストが変わります。メッシュを再生成し、固定節点を確認し直してください。作成済みデッキと FE 節点の固定条件は偶然の一致では引き継がれません。子領域をさらに分割することもできます。

拒否または未完了の分割はリビジョン数・設定・元図面を変えません。直線・円弧・クランプされたスプライン（通過点スプラインと非周期の閉じた通過点スプラインを含む）に対応します。周期または非クランプのスプラインは分割できません。送信済み（ロック済み）のスナップショット、3D プレビュー、未保存の編集があるリビジョンでは分割できません。先に保存してください。

## 4. 結果の読み方

- **表示変数** は U（変位）です。**成分** で大きさまたは |U1| / |U2| / |U3| を選べます。成分表示は絶対値
  で彩色し、プローブ欄には符号付きの値を表示します。
- **カラー範囲** は変位と応力で独立です。変位の大きさと U 成分は **0–5 mm**、von Mises と応力成分は
  **0–0.50 MPa** の固定既定で始まります。`固定` は表示上の既定、`自動` はその量の解析全体の実測最大、
  `手動` は表示単位付きの最小・最大を編集できます。**範囲をリセット** で既定に戻ります。空欄・非有限・
  上下逆の入力はローカルで拒否され、直前の有効な表示が残ります。0 は有効な最小値です。範囲はソルバー
  値を書き換えません。
- 凡例は両端を単位付きで示し、上限を超える値と正の下限を下回る値を明示します。プローブ値・グラフ・
  エクスポート CSV は切り詰めません。
- 等高線は 1 つの飽和した青－シアン－緑－黄－赤のパレットを、ビューポート・アクター色・凡例で共有します。
  材料色とグラフ軸は別です。
- 剛体パネルは積分点応力を持ちませんが、実測の節点 U に従って移動します。応力のない面は中立色の線を
  保ち、存在しない等高線は作りません。実測 U がない節点は基準位置に残り、プローブは取得不可と表示します。
- 節点・要素のプローブは `インスタンス名 · 種別 番号` の形式で表示されます。インスタンスをまたいで番号
  が混在することはありません。
- **取得できない出力** には、その実行で要求していない、または抽出できなかった変数が表示されます。値が
  0 として代用されることはありません。
- 表示範囲・カメラ・色スケールは実行全体で固定されます。フレーム再生中に自動でフィットし直すことは
  なく、**フィット**（F キー）で明示的に戻します。移動・ズームはフレーム送り、再生、構成部品の切り替
  え、変形表示の切り替えでも維持されます。色スケールは実行全体の実測値から決まり、フレームごとに変わり
  ません。
- **フレームを再生** は一時停止状態から始まります。**ループ** は既定で有効で、最後のフレームを 1 回分
  表示してから先頭フレームへ戻り、繰り返します。ループを外すと最終フレームで停止します。一時停止と
  スクラブはいつでも使えます。フレームの読み込みに失敗した場合は直前の有効なシーンを表示したまま
  フレーム番号を示します。0 または 1 フレームの実行は静的表示で、タイマーは動きません。
- **メッシュ辺** は解析結果で既定で表示され、独立して切り替えられます。**材料の輪郭** は既定で非表示の表示設定で、材料ごとの外周（色は材料色）と異種材料の内部界面（太い中立色）を描き、材料名と色見本、界面数を表示します。メッシュ辺・節点マーカー・表示量・変形倍率とは独立し、変形表示と倍率に従って動きます。CAD 領域データを持たない旧結果では利用できない理由を表示します。**パネル応答** は、選択したステップの基準点反力を、そのステップ自身の移動方向へ投影した値と、ステップ開始からの移動量の関係を示します。グラフの上には「閉じ方向のドアパネル反力 (N)」のような完全な説明を折り返して表示し、縦軸は単位付きの短い表題（例: 力 (N)）にして 210 px の高さに収めます。グラフ下にはステップ、役割、インスタンス、RP ラベル、実際の方向 **d** = (dx, dy) と全体 +X からの反時計回りの角度、力の基準が表示されます。ボデー着座と閉じは別の軸を使うため、ボデーの上向き着座をドアの閉じ方向へ投影することはありません。ステップ情報のない旧記録は、別ステップの方向を借りずにその旨を表示します。
- **ドアパネル接触圧** は、投入したデッキが要求している場合に荷重－変位の下に表示されます。表示中フレームのドア側節点 `CPRESS` を **kPa** で、選択したドアプロファイルに沿った累積距離 **mm** に対して描きます。プロファイルの向きと位置は ODB 自身の R2D2 接続から一度だけ決め（開いたチェーンは `(x, y, nodeLabel)` が最小の端点から開始）、ドアの移動・回転、接続順の反転、フレーム変更、ズームで軸は動きません。換算は `p_kPa = 1000 × CPRESS_MPa` の 1 箇所だけで、換算幅・ソルバー厚さ・力の基準・Y 反転は接触圧に影響しません。節点の詳細にはネイティブの MPa も表示します。接続したドアプロファイルが複数ある場合はプロファイル選択が表示されます。
- **接触圧の矢印** は既定で有効で、表示トグルがあります。向きは同じ節点の実測 `CNORMF`（組立座標系、正規化）、長さは表示中の接触圧に比例し、解析全体で 1 つのスケールを使います。基準矢印は解析全体の最大値を kPa で示します。矢印は表示中の変形節点に固定されるため、パン・ズーム・変形表示・変形倍率に追従します。選択対象にはならず、表示量・プローブ・成果物を変えません。接触圧があっても `CNORMF` の向きがない節点は、グラフに残して矢印を描きません。グラフ上の点をホバーまたは選択すると、ドア上の同じ節点を特定し、プロファイル、位置、kPa、ネイティブ MPa、符号付き `CNORMF` 成分（N）を表示します。実測の 0 は 0 の線として残り、欠測は線を分断し、矛盾する重複観測は件数付きで非表示にします。
- **CNORMF（接触法線力）** は実測されていれば表示量として選べます。等高線は節点の大きさ（N）で、プローブは符号付き Fx/Fy 成分を保持します。ドア側の接触領域は投入した定義（アプリのドア－シール対、または外部 ODB の一般接触集合）に基づいて表示し、シール・ボデー・剛体基準点の同じ節点番号は別の同一性として扱います。接触圧または力の欠測は明示的に取得不可とし、推定しません。この機能より前の結果と DEMO 結果は「この結果にはドアパネル接触圧がありません」と表示し、荷重－変位曲線・エクスポート・元の成果物はそのまま読めます。
- **符号の表示** で X / Y の符号を反転できます。これはグラフと表示中曲線のエクスポートだけに作用し、保存済みの結果は書き換えません。Y 反転中は、表示のために Y 軸を反転していることと、ソルバーの生の反力は変わらないことを画面に表示します。
- **荷重 CSV を書き出す（2 行）** は、A 列に工学ラベル、B 列以降に数値サンプルを持つ表計算向け CSV を出力します。1 行目は `stroke(mm)` で、有効な共通基準サンプルからのステップ相対の実測変位の大きさ √((U1−U1₀)²+(U2−U2₀)²) です。2 行目は `F (…)` で、記録済みの基準で正規化済みの符号付き投影反力です — 既定の換算幅 100 mm なら `F (N/100mm)`、80 mm なら `F (N/80mm)`、1 mm あたりなら `F (N/mm)`、換算幅が不明な旧結果なら `F (N)`。値を二重に換算し直すことはありません。**書き出し間隔** は編集可能（既定 **1.0 mm**）で、格子は整数倍から作り、最後の実測ストロークが格子点でない場合は 1 回だけ追加します。実測位置では実測値、隣接する 2 つの有効サンプル間では線形補間します。欠測は空欄のままで、間を補間しません。同じストロークに異なる荷重がある保持や除荷・再負荷では等間隔出力が曖昧になるため、理由を表示し、**元の取得順サンプル** で取得順の行を出力できます。X 反転は書き出すストロークの符号を変えず、Y 反転は反力に 1 回だけ作用します。ファイル名はパネル、ステップ、基準、間隔、符号を示します。
- **ドア面圧 CSV を書き出す（2 行）** は、選択したドアプロファイルの `door station(mm)` と `CPRESS (kPa)` を **表示中** のフレームについて出力します。**書き出し間隔** は編集可能（既定 **1.3 mm**）で、補間は時間や全体 X ではなく弧長位置に対して行います。最後の実測位置は 1 回だけ追加します。欠測は空欄、実測の全 0 プロファイルは有効です。**元のプロファイル節点** は、粗い等間隔では取り逃がす狭いピークを含め、実測節点をすべて保持します。プロファイル切替、スクラブ、遅延フレーム、フレームと一致しない面圧配列では、グラフ・出力バイト・ファイル名が同じフレームを指し、利用できない場合は理由付きでボタンが無効になります。ファイル名はプロファイル、フレーム、ステップ、間隔を示します。
- **履歴 CSV をダウンロード** は未加工の成果物です。表示上の符号反転と書き出し間隔はブラウザ内だけに作用します。
- 投影形式より前に作成された結果も開けます。その場合は元の U2 / RF2（符号付き）を表示し、その旨を明示します。

## 5. Abaqus のみ実行と履歴の識別

新しい実行はすべて Abaqus/Standard を使用し、有効なランチャー設定とライセンスが必要です。実行モード選択と合成シナリオ選択は削除されました。`DEMO` を明示して投入すると、対処方法を示す検証エラーが返り、何もキューに登録されません。キューに残っていた旧 DEMO ジョブは、ライセンス実行へ変換されたり再起動されたりせず、理由を記録して停止します。

過去の DEMO 実行、結果画面、エクスポート、および `DEMO — synthetic results, not an Abaqus analysis.` という表示は引き続き参照できます。過去の DEMO 出力を設計判断や材料モデルの検証に使用しないでください。

## 7. 知っておくべき制約

- 解析は 2D 平面応力のみです。3D は形状確認用です。
- 対応要素は CPS3 / CPS4R、剛体パネルは R2D2 です。
- 接触はハードコンタクト、パネルは 1 枚、移動方向は Y のみです。ボディ→ドアの 2 ステップ、斜め移動、
  ドア↔シール、ボデー↔シール、シール↔シールの摩擦係数は独立して設定できます。内部の接合パーティション境界は露出面ではなく、剛体同士の接触は除外されます。
- 固定節点はメッシュ節点の選択です。メッシュが変わる編集では新しいメッシュと固定節点の再確認が必要
  です。節点番号が一致していても、以前の選択が正しいとはみなしません。
- スプラインは正確に読み込みますが、閉曲線・周期曲線など OCC が正確な B-スプラインを受け取れない
  場合は、宣言した弦誤差（既定 0.02 mm）でメッシュ化します。
- 分割は 1 操作につき、材料を持つ 1 つのシール領域に対する 1 本以上の投影直線ガイドです。2 つ以上の
  子領域を作れます。直線・円弧とクランプされた制御点または通過点スプライン（非周期の閉曲線を含む）を
  解析的に分割します。周期・非クランプスプラインは分割できません。薄片や対象外・未完成のガイドを含む
  ドラフトは保存されません。1 領域だけ残るドラフトは編集可能です。各ガイドの削除やキャンセルができます。適用後の
  リビジョンは不変です。通常の削除規則に従うか、以前のリビジョンから続けてください。
- 分割で生じた子領域へ FE 節点の固定条件は引き継がれません。再メッシュと固定節点の再確認が必要です。
- DWG は同梱のネイティブリーダーで読み込みます。ヘルパーが不完全な場合は不足している同梱コンポーネント名を表示し、`integrations/dwg/bin` の復元を求めます。ODA のインストールは不要です。
- 物理的な妥当性（接触開始位置、反力の大きさ、メッシュ収束）は信頼できる参照値との比較では未検証で
  す。ライセンスを使用したドアパネル単独の閉じ解析を 1 件実行しており、結果は
  [engineering-validation.md](engineering-validation.md) に記録しています。

## 8. データの場所

データは `%LOCALAPPDATA%\SimplifyAbaqus` に保存されます。ディレクトリ名は旧名称のままですが、これは
既存のプロジェクトを失わないための意図的な互換仕様です。バックアップと復元の手順は
[migration-and-recovery.md](migration-and-recovery.md) を参照してください。
