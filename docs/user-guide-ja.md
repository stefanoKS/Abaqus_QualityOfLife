# Abaqus QOL ユーザーガイド

対象: ウェザーストリップ断面の解析を担当する設計・解析技術者。

Abaqus QOL はローカル PC 上で動作する単独利用の作業環境です。データはインターネットへ送信されません。
画面は日本語を既定とし、右上の言語選択で English に切り替えられます。選択は保存され、再読み込み後も
維持されます。数値・単位・材料 ID・節点番号・要素番号など工学的な値は言語を切り替えても変化しません。

起動は `start-abaqus-qol.cmd` をダブルクリックします。初回は Python 3.11 以降と Node.js が入っていれ
ば、リポジトリ内の Python 環境とブラウザ用ビルドを自動で準備し、作業環境とワーカーを起動して、準備完了
を確認してから既定のブラウザを開きます。再度ダブルクリックした場合は起動中のインスタンスを開きます。必
要なソフトウェアが無い場合や、ポートが別のアプリケーションに使われている場合は、対処方法を画面に表示し
ます。ログインは不要です。

## 1. 画面構成

| 領域 | 内容 |
|---|---|
| 上部バー | 製品ロゴと製品名、作業画面 / ダッシュボードの切り替え、実行環境の表示、言語選択 |
| 左パネル | ワークフロー（現在の工程と設定状況）とアセンブリツリー |
| 中央 | 形状・メッシュ・結果のビューポート |
| 右パネル | 選択対象に応じたプロパティ編集 |
| 下部 | 保存状態、検証メッセージ、実行フェーズ |

ワークフローの各工程には設定状況が表示されます。

- **チェック** : 必要な設定が完了しています。
- **丸** : まだ設定されていません。
- **鍵** : 前提となる工程が未完了のため実行できません。

工程の完了は「その画面を開いたかどうか」では判断されません。実際の保存済み設定から判定されます。

## 2. 基本的な流れ

1. **ダッシュボード → 新規プロジェクト** でプロジェクト（グループ）と最初のモデルをまとめて作成しま
   す。プロジェクトは「5q45」のような入れ物、モデルはその中の解析対象です。**モデル名**を空欄にする
   とプロジェクト名が使われます。初期形状は 2D 中空バルブ断面または 3D 押出セグメントです。
2. グループ見出しの **モデルを追加** で同じプロジェクトに 2D / 3D のモデルを追加できます。各モデルは
   独自のリビジョン履歴と実行履歴を持ち、**リビジョン** で一覧、**モデルを複製** で同じグループ内に
   独立したモデルを作成できます。
3. **図面読込** で DXF / DWG を読み込む場合は、座標が mm であることを確認してから実行します。読み込み
   はバックグラウンドで処理され、完了すると新しいリビジョンが作成されます。対応エンティティは
   `LINE`、`ARC`、`CIRCLE`、閉じた `LWPOLYLINE`、`SPLINE` です。スプラインは制御点・ノット・重みを
   保った正確な B-スプラインとして、通過点のみのスプラインは AutoCAD 互換の 3 次補間として保持する
   ため、表示もメッシュも弦ではなく作図された曲線に従います。
4. **構成部品** で各構成部品に「ウェザーストリップ（シール部）」「可動パネル」などの役割を割り当てます。
5. **材料設定** で領域ごとに材料カードを割り当て、必要に応じて材料特性を編集します。
6. **固定条件・接触条件** で固定するエッジを選択し、摩擦係数を設定します。
7. **移動条件** で初期 Y オフセット、Y 方向の強制移動量（負値）、ステップ時間を設定します。
8. **リビジョンを保存** を押します。未保存の変更があると画面下部に警告が表示されます。
9. **メッシュ → メッシュを生成** で要素分割します。この時点では固定節点の選択は不要です。
10. **固定節点（WSFIX）** で **矩形選択モード** を有効にし、固定したい WS 節点を矩形で囲みます。左
    ドラッグで選択、**Shift + ドラッグ**でパン、ホイールでズームします。矩形の動作は
    **置き換え / 追加 / 除外** から選び、**選択をクリア** でやり直せます。選択節点数を確認して
    **固定節点を保存** を押します。固定されるのは選択した節点だけで、矩形が CAD エッジ全体に広がる
    ことはありません。編集可能な旧モデルでは **旧固定エッジ N 本を節点に解決** でハイライトを確認
    し、その内容を固定節点として保存できます。
11. **入力デッキ作成 → 入力デッキを作成** で、保存済みメッシュと固定節点からデッキを作ります。
12. **解析条件確認・実行** で内容を確認し、DEMO または ABAQUS で投入します。
13. **解析結果** でフレーム再生、節点・要素のプローブ、ドア応答曲線の確認、表示中曲線のエクスポート、
    生データ CSV のダウンロードを行います。

### メッシュの再利用と無効化

メッシュは形状・構成部品の役割・領域の充填状態・分割条件で識別され、解析条件とは切り離されています。
移動量・ステップ時間・摩擦係数・材料値の変更ではメッシュと固定節点は維持され、入力デッキの作り直し
だけが必要です。形状、役割、空洞の充填、メッシュサイズや分割条件を変更すると旧メッシュは非互換と
なり、画面にその旨が表示され、新しいメッシュ上で固定節点の再確認が必要になります。作成済みのデッキ
も投入できなくなります。再読み込みや再表示で自動的に再メッシュされることはなく、確認済みのメッシュ
とハイライトが復元されます。

## 3. 材料の編集

**材料設定 → 材料カード一覧** に既存のカードが表示されます。

- **新規作成** : 空の線形弾性カードを作成します。
- **複製** : 選択中のカードを複製します。
- **削除** : いずれかの領域で使用中のカードは削除できません。先に割当を解除してください。
- **材料名 / 表示色** : 自由に変更できます。
- **材料モデル** : 線形弾性 または ハイパーフォーム（試験データ）を選択します。

線形弾性では密度、ヤング率、ポアソン比を入力します。ハイパーフォームでは一軸試験データ（公称応力、
軸公称ひずみ、横公称ひずみ）を表形式で編集できます。表計算ソフトの 3 列を貼り付けることもできます。

入力値に問題がある場合は、保存前にエラーが表示され **リビジョンを保存** が押せなくなります。工学的な
助言（例: 軸ひずみが単調増加していない）は警告として表示されますが、保存は妨げません。

カードの値が実際に変わった場合のみ、保存時にカード版数（v）が増えます。過去のリビジョンは当時の材料値
を保持したまま残ります。未割当の材料カードは入力デッキに出力されません。

## 4. 結果の読み方

- **表示変数** は U（変位）です。**成分** で大きさまたは |U1| / |U2| / |U3| を選べます。成分表示は絶対値
  で彩色し、プローブ欄には符号付きの値を表示します。
- 節点・要素のプローブは `インスタンス名 · 種別 番号` の形式で表示されます。インスタンスをまたいで番号
  が混在することはありません。
- **取得できない出力** には、その実行で要求していない、または抽出できなかった変数が表示されます。値が
  0 として代用されることはありません。
- **ドア応答** は、パネル基準点の反力を閉じ方向へ投影した値と、閉じ開始からの移動量の関係を示します。
  シールが抵抗する場合は右上がりの正の曲線になります。有効な方向はグラフの下に表示されます。
- **符号の表示** で X / Y の符号を反転できます。これはグラフと表示中曲線のエクスポートだけに作用し、
  保存済みの結果は書き換えません。
- **表示中の曲線をエクスポート** は、グラフに表示されている値そのものを CSV にします。パネル、ステッ
  プ、方向、単位、符号、正規化、DEMO / ABAQUS の由来を `#` 行に記載し、生の符号付き成分も併記します。
  **履歴 CSV をダウンロード** は未加工の成果物です。
- 投影形式より前に作成された結果も開けます。その場合は元の U2 / RF2（符号付き）を表示し、その旨を明示
  します。

## 5. DEMO と ABAQUS の違い

**DEMO** は作業環境とキューの動作確認用です。場の値と荷重曲線は合成データであり、Abaqus の解析結果で
はありません。ダッシュボード、実行バナー、結果画面、凡例、CSV、メタデータに
`DEMO — synthetic results, not an Abaqus analysis.` と表示されます。

**ABAQUS** は実際のライセンスを使用して Abaqus/Standard を実行します。実行には有効なライセンスと
ランチャーの設定が必要です。DEMO の結果を設計判断や材料モデルの検証に使用しないでください。

## 6. エラーメッセージ

| 表示 | 対処 |
|---|---|
| Abaqus launcher not configured | ランチャーの環境変数を設定し、アプリケーションを再起動します。 |
| DWG converter not configured | ODA File Converter のパスを設定するか、DXF で出力し直します。 |
| Unsupported DXF entities | ブロックを分解し、`LINE` / `ARC` / `CIRCLE` / `SPLINE` / 閉じた `LWPOLYLINE` で出力します。 |
| Spline knot vector length must equal control points + degree + 1 | ノット数と制御点数が矛盾しています。曲線を出力し直します。 |
| Spline endpoints disagree with its vertices | スプラインの端点が隣接曲線と一致するよう図面を出力し直します。 |
| Every seal edge must belong to a material region | すべてのエッジが領域に属するよう図面を修正します。 |
| Assign the seal role and a material to every section region | 材料設定で未割当の領域を解消します。 |
| Requested mesh exceeds the pilot mesh budget | 全体サイズを大きくして要素数を減らします。 |
| Degenerate or inverted element | 要素サイズを変更するか、境界形状を修正します。 |
| Unknown / worker disconnected | 実行ディレクトリのログとプロセスを確認します。詳細は次章のドキュメントを参照してください。 |

## 7. 知っておくべき制約

- 解析は 2D 平面応力のみです。3D は形状確認用です。
- 対応要素は CPS3 / CPS4R、剛体パネルは R2D2 です。
- 接触はハードコンタクト、パネルは 1 枚、移動方向は Y のみです。ボディ→ドアの 2 ステップ、斜め移動、
  接触面ペアごとの摩擦上書きは未対応です。
- 固定節点はメッシュ節点の選択です。メッシュが変わる編集では新しいメッシュと固定節点の再確認が必要
  です。節点番号が一致していても、以前の選択が正しいとはみなしません。
- スプラインは正確に読み込みますが、閉曲線・周期曲線など OCC が正確な B-スプラインを受け取れない
  場合は、宣言した弦誤差（既定 0.02 mm）でメッシュ化します。
- DWG の読み込みには ODA File Converter のインストールが必要です。無い場合は
  *DWG converter not configured* と表示され、DXF 出力を求めます。
- 物理的な妥当性（接触開始位置、反力の大きさ、メッシュ収束）は信頼できる参照値との比較では未検証で
  す。ライセンスを使用したドア単独の閉じ解析を 1 件実行しており、結果は
  [engineering-validation.md](engineering-validation.md) に記録しています。

## 8. データの場所

データは `%LOCALAPPDATA%\SimplifyAbaqus` に保存されます。ディレクトリ名は旧名称のままですが、これは
既存のプロジェクトを失わないための意図的な互換仕様です。バックアップと復元の手順は
[migration-and-recovery.md](migration-and-recovery.md) を参照してください。
