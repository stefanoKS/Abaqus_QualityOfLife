# Abaqus QOL ユーザーガイド

対象: ウェザーストリップ断面の解析を担当する設計・解析技術者。

Abaqus QOL はローカル PC 上で動作する単独利用の作業環境です。データはインターネットへ送信されません。
画面は日本語を既定とし、右上の言語選択で English に切り替えられます。選択は保存され、再読み込み後も
維持されます。数値・単位・材料 ID・節点番号・要素番号など工学的な値は言語を切り替えても変化しません。

## 1. 画面構成

| 領域 | 内容 |
|---|---|
| 上部バー | 製品名、作業画面 / ダッシュボードの切り替え、実行環境の表示、言語選択 |
| 左パネル | ワークフロー（現在の工程と設定状況）とアセンブリツリー |
| 中央 | 形状・メッシュ・結果のビューポート |
| 右パネル | 選択対象に応じたプロパティ編集 |
| 下部 | 保存状態、検証メッセージ、実行フェーズ |

ワークフローの各工程には設定状況が表示されます。

- **チェック** : 必要な設定が完了しています。
- **丸** : まだ設定されていません。
- **鍵** : 前提となる工程が未完了のため実行できません。

工程の完了は「その画面を開いたかどうか」では判断されません。実際の保存済み設定から判定されます。

## 2. 基本的な流れ

1. **ダッシュボード → 新規プロジェクト** でプロジェクトを作成します。初期形状は 2D 中空バルブ断面また
   は 3D 押出セグメントです。
2. **図面読込** で DXF / DWG を読み込む場合は、座標が mm であることを確認してから実行します。読み込み
   はバックグラウンドで処理され、完了すると新しいリビジョンが作成されます。
3. **構成部品** で各構成部品に「ウェザーストリップ（シール部）」「可動パネル」などの役割を割り当てます。
4. **材料設定** で領域ごとに材料カードを割り当て、必要に応じて材料特性を編集します。
5. **固定条件・接触条件** で固定するエッジを選択し、摩擦係数を設定します。
6. **移動条件** で初期 Y オフセット、Y 方向の強制移動量（負値）、ステップ時間を設定します。
7. **リビジョンを保存** を押します。未保存の変更があると画面下部に警告が表示されます。
8. **メッシュ → メッシュと入力を生成** で要素分割と入力デッキ生成を行います。
9. **解析条件確認・実行** で内容を確認し、DEMO または ABAQUS で投入します。
10. **解析結果** でフレーム再生、節点・要素のプローブ、荷重－変位曲線の確認、CSV のダウンロードを行い
    ます。

## 3. 材料の編集

**材料設定 → 材料カード一覧** に既存のカードが表示されます。

- **新規作成** : 空の線形弾性カードを作成します。
- **複製** : 選択中のカードを複製します。
- **削除** : いずれかの領域で使用中のカードは削除できません。先に割当を解除してください。
- **材料名 / 表示色** : 自由に変更できます。
- **材料モデル** : 線形弾性 または ハイパーフォーム（試験データ）を選択します。

線形弾性では密度、ヤング率、ポアソン比を入力します。ハイパーフォームでは一軸試験データ（公称応力、
軸公称ひずみ、横公称ひずみ）を表形式で編集できます。表計算ソフトの 3 列を貼り付けることもできます。

入力値に問題がある場合は、保存前にエラーが表示され **リビジョンを保存** が押せなくなります。工学的な
助言（例: 軸ひずみが単調増加していない）は警告として表示されますが、保存は妨げません。

カードの値が実際に変わった場合のみ、保存時にカード版数（v）が増えます。過去のリビジョンは当時の材料値
を保持したまま残ります。未割当の材料カードは入力デッキに出力されません。

## 4. 結果の読み方

- **表示変数** は U（変位）です。**成分** で大きさまたは |U1| / |U2| / |U3| を選べます。成分表示は絶対値
  で彩色し、プローブ欄には符号付きの値を表示します。
- 節点・要素のプローブは `インスタンス名 · 種別 番号` の形式で表示されます。インスタンスをまたいで番号
  が混在することはありません。
- **取得できない出力** には、その実行で要求していない、または抽出できなかった変数が表示されます。値が
  0 として代用されることはありません。
- **荷重－変位** はパネルの U2 と RF2（符号付き）です。単位は軸ラベルと凡例に表示されます。

## 5. DEMO と ABAQUS の違い

**DEMO** は作業環境とキューの動作確認用です。場の値と荷重曲線は合成データであり、Abaqus の解析結果で
はありません。ダッシュボード、実行バナー、結果画面、凡例、CSV、メタデータに
`DEMO — synthetic results, not an Abaqus analysis.` と表示されます。

**ABAQUS** は実際のライセンスを使用して Abaqus/Standard を実行します。実行には有効なライセンスと
ランチャーの設定が必要です。DEMO の結果を設計判断や材料モデルの検証に使用しないでください。

## 6. エラーメッセージ

| 表示 | 対処 |
|---|---|
| Abaqus launcher not configured | ランチャーの環境変数を設定し、アプリケーションを再起動します。 |
| DWG converter not configured | ODA File Converter のパスを設定するか、DXF で出力し直します。 |
| Every seal edge must belong to a material region | すべてのエッジが領域に属するよう図面を修正します。 |
| Assign the seal role and a material to every section region | 材料設定で未割当の領域を解消します。 |
| Requested mesh exceeds the pilot mesh budget | 全体サイズを大きくして要素数を減らします。 |
| Degenerate or inverted element | 要素サイズを変更するか、境界形状を修正します。 |
| Unknown / worker disconnected | 実行ディレクトリのログとプロセスを確認します。詳細は次章のドキュメントを参照してください。 |

## 7. 知っておくべき制約

- 解析は 2D 平面応力のみです。3D は形状確認用です。
- 対応要素は CPS3 / CPS4R、剛体パネルは R2D2 です。
- 接触はハードコンタクト、パネルは 1 枚、移動方向は Y のみです。
- 物理的な妥当性（接触開始位置、反力の大きさ、メッシュ収束）は未検証です。
  [engineering-validation.md](engineering-validation.md) を参照してください。

## 8. データの場所

データは `%LOCALAPPDATA%\SimplifyAbaqus` に保存されます。ディレクトリ名は旧名称のままですが、これは
既存のプロジェクトを失わないための意図的な互換仕様です。バックアップと復元の手順は
[migration-and-recovery.md](migration-and-recovery.md) を参照してください。
